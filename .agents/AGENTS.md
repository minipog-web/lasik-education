# Strict Deployment Prohibition Rules

- **NEVER deploy to Netlify, GitHub, Vercel, or any hosting platform** unless specifically and explicitly instructed by the user in their prompt.
- **Do NOT run any Netlify commands** (`npx netlify deploy`, `npx netlify-cli deploy`, `netlify deploy`, etc.) or push to GitHub/remotes after making code changes unless the user explicitly commands a deployment in that prompt.
